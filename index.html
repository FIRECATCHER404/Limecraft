Java Edition Launcher

Limecraft

A fast, dark-mode Minecraft launcher built for people who swap versions a lot.

  • Microsoft + Offline modes
  • Installs missing versions automatically
  • Snapshot, experimental, and legacy support

Smart Version Flow

Pick a version and press Launch. If it is not installed yet, Limecraft pulls jars, libraries, assets, then starts automatically.

Built for Testing

Search by ID, keep your last selected version, view live game logs, and swap Java runtime quickly from the launcher.

Actual QoL

Launch/Kill toggle, remembered offline username, remembered account mode, and a UI tuned for fast repeat launches.
